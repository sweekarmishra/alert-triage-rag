# Benign Anomaly Triage
## [RB-BENIGN-01] Identifying false positives
Traffic spikes that match scheduled backups, software updates, load tests, marketing campaigns or authorized vulnerability scans from the security team. A single user mistyping a password a few times and then logging in successfully. Verify against the change calendar and the asset owner before escalating.
## [RB-BENIGN-02] Closing the alert
Document the business reason and the person who confirmed it. Tune the detection threshold or add an allowlist entry so the same activity does not alert again. No containment is required.
